# Omelette Recipe Page

A simple static web page that displays a Classic Omelette recipe, built with HTML and CSS.

## Project Structure

```
FJS25_proyect_1/
├── index.html        # Main HTML file
├── CSS/
│   └── styles.css    # Stylesheet
├── Assets/
│   └── *.png         # Recipe image
└── README.md
```

## Features

- Displays a Classic Omelette recipe with:
  - Prep, cook, and total time
  - Ingredients list
  - Step-by-step instructions
  - Nutrition facts
- Responsive layout with a clean, readable design

## How to Use

Open `index.html` in any modern web browser — no build tools or dependencies required.

## Technologies

- HTML5
- CSS3
